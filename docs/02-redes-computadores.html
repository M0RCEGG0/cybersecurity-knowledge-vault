🌐 Fundamentos de Redes para Cibersegurança

Visão de Cibersegurança: Redes são o meio de transporte de dados e o principal vetor de ataque na internet. Compreender o Modelo OSI, a pilha TCP/IP, endereçamento IP/máscaras e as portas dos protocolos essenciais é indispensável para análise de tráfego (Wireshark), firewalling e detecção de invasões.

1. Modelo OSI vs. Modelo TCP/IP

O Modelo OSI é uma referência conceitual de 7 camadas, enquanto o TCP/IP é a implementação prática dominante na internet:

    MODELO OSI (7 Camadas)                 MODELO TCP/IP (4 Camadas)       PDU / Protocolos
┌────────────────────────────────┐
│ 7. Aplicação                   │ ──┐
├────────────────────────────────┤   ├─► 4. Aplicação              [Dados] HTTP, HTTPS, SSH, DNS, DHCP
│ 6. Apresentação                │   │
├────────────────────────────────┤   │
│ 5. Sessão                      │ ──┘
├────────────────────────────────┼─────────────────────────────────┼────────────────────────────────────────
│ 4. Transporte                  │ ────► 3. Transporte             [Segmento] TCP (confiável), UDP (rápido)
├────────────────────────────────┼─────────────────────────────────┼────────────────────────────────────────
│ 3. Rede                        │ ────► 2. Internet / Rede        [Pacote] IP (IPv4/IPv6), ICMP, ARP
├────────────────────────────────┼─────────────────────────────────┼────────────────────────────────────────
│ 2. Enlace de Dados             │ ──┐
├────────────────────────────────┤   ├─► 1. Acesso à Rede / Físico [Quadro/Bits] Ethernet, Wi-Fi, MAC Address
│ 1. Física                      │ ──┘
└────────────────────────────────┘

2. Transporte: TCP vs. UDP

Característica TCP (Transmission Control Protocol) UDP (User Datagram Protocol)
Conexão Orientado à conexão (Three-Way Handshake) Não orientado à conexão (Connectionless)
Confiabilidade Garante entrega, reordena pacotes, retransmite perdas Não garante entrega nem ordem (envia e esquece)
Velocidade Mais lento (overhead de cabeçalho e confirmações) Muito rápido (mínimo overhead)
Casos de Uso Web (HTTP/HTTPS), SSH, FTP, envio de e-mails Streaming ao vivo, jogos online, VoIP, consultas DNS

O Three-Way Handshake do TCP (Alvo de ataques como SYN Flood):

  1. SYN: Cliente envia pacote de sincronização: "Quero iniciar conexão!"
  2. SYN-ACK: Servidor responde concordando: "Recebi o pedido, pronto para conectar!"
  3. ACK: Cliente confirma recebimento: "Conexão estabelecida! Trocando dados."

3. Endereçamento: MAC, IPv4 e Sub-redes

  • Endereço MAC (Camada 2 - Enlace): Físico, gravado no hardware de rede (48 bits em hexadecimal, ex: 00:1A:2B:3C:4D:5E).
  • Endereço IPv4 (Camada 3 - Rede): Lógico e roteável (32 bits, 4 octetos decimais, ex: 192.168.1.1).
  • Faixas de IP Privados (RFC 1918) — Não roteáveis na internet pública:
    • Classe A: 10.0.0.0 a 10.255.255.255
    • Classe B: 172.16.0.0 a 172.31.255.255
    • Classe C: 192.168.0.0 a 192.168.255.255
    • Loopback (Localhost): 127.0.0.1

4. Portas e Protocolos Fundamentais

Porta Protocolo Transporte Função / Impacto de Segurança
20/21 FTP TCP Transferência de arquivos (inseguro: envia credenciais em texto claro).
22 SSH TCP Acesso remoto criptografado seguro.
23 Telnet TCP Acesso remoto legado e inseguro (sem criptografia).
25 SMTP TCP Envio de mensagens de e-mail entre servidores.
53 DNS UDP/TCP Resolução de nomes (converte domínios em IPs).
67/68 DHCP UDP Atribuição dinâmica de configurações de IP aos hosts.
80 HTTP TCP Navegação web comum (tráfego sem criptografia).
443 HTTPS TCP Navegação web segura criptografada com TLS/SSL.
445 SMB TCP Compartilhamento de arquivos Windows (vetor clássico de exploração, ex: EternalBlue).
3389 RDP TCP Área de Trabalho Remota da Microsoft.

5. Comandos Essenciais de Diagnóstico e Reconhecimento

# Testar conectividade via ICMP Echo Request
ping 8.8.8.8

# Rastrear a rota e saltos até o destino
traceroute example.com     # No Linux
tracert example.com        # No Windows

# Consultar registros de resolução de nomes DNS
nslookup example.com
dig example.com +short     # No Linux

# Ver conexões ativas, portas abertas e processos ouvindo
netstat -tulnp             # No Linux
ss -tulnp                  # Alternativa moderna e mais rápida no Linux

# Inspecionar tabela de endereços físicos (MAC) resolvidos via ARP
arp -a
