👤 Gerenciamento de Usuários e Grupos no Linux

Princípio de Cibersegurança: Toda a governança de acesso no Linux gira em torno do Menor Privilégio (PoLP — Principle of Least Privilege): nenhum usuário deve rodar como root direto no dia a dia. Usamos contas com privilégios limitados e elevamos acessos pontualmente via sudo para garantir trilha de auditoria.

1. Os 4 Arquivos Críticos de Identidade

  • /etc/passwd: Informações públicas das contas (Login, UID, GID, pasta home, shell). Leitura pública para processos.
  • /etc/shadow: Armazena os hashes criptográficos das senhas e regras de validade/expiração. Acesso exclusivo do root (permissão 0640 ou 0600). Alvo principal de invasores para ataques de quebra de hash.
  • /etc/group: Cadastro dos grupos do sistema e seus respectivos membros.
  • /etc/sudoers: Define quais usuários ou grupos podem executar comandos com privilégio elevado. Sempre editar usando sudo visudo para validar sintaxe e evitar bloqueios acidentais.

Anatomia de um Registro no /etc/passwd

secuser:x:1001:1001:Security Analyst,,,:/home/secuser:/bin/bash
  │   │   │    │          │             │         └─ Shell padrão
  │   │   │    │          │             └─ Diretório Home
  │   │   │    │          └─ Comentário / Nome completo (GECOS)
  │   │   │    └─ GID (ID do Grupo Principal)
  │   │   └─ UID (0=root, 1 a 999=serviços do sistema, 1000+=usuários comuns)
  │   └─ "x" indica que a senha real/hash está protegida no /etc/shadow
  └─ Nome da Conta (Username)

2. Comandos Práticos de Administração de Contas

# Criar usuário com pasta home (-m) e shell interativo (-s)
sudo useradd -m -s /bin/bash novo_usuario

# Definir ou resetar a senha da conta
sudo passwd novo_usuario

# Criar um grupo de segurança
sudo groupadd sec_team

# Adicionar usuário a um grupo secundário (MUITO CUIDADO com o -a!)
sudo usermod -aG sudo,sec_team novo_usuario

# Bloquear e Desbloquear conta (ex: desligamento temporário)
sudo passwd -l novo_usuario   # -l = Lock (desativa login)
sudo passwd -u novo_usuario   # -u = Unlock (reativa login)

# Deletar usuário e remover todos os seus arquivos pessoais (-r)
sudo userdel -r novo_usuario

3. Auditoria e Hardening em Cibersegurança

Comando / Prática Objetivo de Segurança Risco Mitigado
sudo chage -l usuario Consulta validade e regras de expiração de senha. Contas antigas e esquecidas no servidor.
sudo chage -M 90 usuario Força a troca periódica de senha a cada 90 dias. Reduz a janela de abuso caso a credencial seja vazada.
sudo usermod -s /usr/sbin/nologin conta Bloqueia login interativo em contas de serviço (ex: www-data). Dificulta shell interativo se uma aplicação web for invadida.
awk -F: '($3 == 0) {print $1}' /etc/passwd Audita contas que possuem UID 0. Detecta backdoors com privilégio total de root criadas por invasores.
⚠️ Pegadinha Clássica de Produção: No comando usermod, nunca execute -G sem a flag -a (append). Se esquecer o -a, o Linux removerá o usuário de todos os outros grupos secundários (inclusive do sudo), revogando seus acessos de administrador!

4. Comandos de Reconhecimento e Auditoria Local

whoami         # Revela qual usuário você é na sessão atual
id             # Revela UID, GID e todos os grupos pertencentes
who / w        # Mostra quem está conectado no servidor e os processos ativos
last           # Histórico dos últimos logins registrados no sistema
lastlog        # Mostra a data do último login de cada usuário cadastrado
