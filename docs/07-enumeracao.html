📑 Enumeração com Nmap & Nmap NSE

Conceito-Chave: Enquanto a Varredura (Scanning) apenas verifica se uma porta está aberta ou fechada, a Enumeração estabelece comunicação ativa com o serviço para extrair dados estruturados: nomes válidos de contas, compartilhamentos SMB desprotegidos, métodos HTTP aceitos e daemons exatos em execução.

1. Enumeração com Parâmetros Nativos do Nmap

# 1. Enumeração profunda de versões com máxima intensidade (0 a 9)
nmap -sV --version-intensity 9 192.168.1.50

# 2. Enumeração de Sistema Operacional com dedução forçada
nmap -O --osscan-guess 192.168.1.50

# 3. Enumeração Agressiva / Tudo-em-Um (-A)
nmap -A 192.168.1.50

2. As Categorias de Scripts do Nmap Scripting Engine (NSE)

Categoria Finalidade Exemplo Típico
default Scripts rápidos e confiáveis recomendados para análise inicial (-sC). Coleta de banners e títulos de páginas web.
discovery Minera ativamente o serviço em busca de recursos e tabelas. http-enum, smb-enum-shares.
safe Scripts desenhados para não causar instabilidade ou queda de serviços. Verificação de certificados TLS/SSL, whois.
vuln Identificação de vulnerabilidades conhecidas (CVEs). smb-vuln-ms17-010 (EternalBlue).
auth Verificação de logins anônimos e credenciais padrão. Checagem de Anonymous Login em FTP.

3. Comandos Práticos de Enumeração Especializada

# 🌐 Enumeração Web (Portas 80 e 443):
# Identificar diretórios conhecidos, softwares e páginas de login
nmap -p 80 --script http-enum 192.168.1.50

# Listar métodos HTTP aceitos pelo servidor (GET, POST, PUT, DELETE)
nmap -p 80 --script http-methods 192.168.1.50

# 📁 Enumeração de SMB / Windows (Porta 445):
# Descobrir compartilhamentos abertos e pastas de rede
nmap -p 445 --script smb-enum-shares 192.168.1.50

# Enumerar usuários locais e de domínio Windows
nmap -p 445 --script smb-enum-users 192.168.1.50

# 📂 Enumeração de FTP (Porta 21):
# Checar se permite autenticação anônima sem credenciais
nmap -p 21 --script ftp-anon 192.168.1.50
