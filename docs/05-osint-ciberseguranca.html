🕵️‍♂️ OSINT — Open Source Intelligence

Visão de Cibersegurança: OSINT é o processo de coletar, analisar e transformar dados disponíveis publicamente e legalmente em informações acionáveis de inteligência. Em um Pentest ou avaliação de segurança, o OSINT compõe a etapa de Reconhecimento Passivo: você obtém vasto conhecimento sobre o alvo sem enviar um único pacote direto contra os servidores dele.

1. O "Pensamento OSINT" (Mindset Investigativo)

A investigação em fontes abertas não consiste em apenas usar ferramentas prontas, mas em seguir uma metodologia lógica:

  1. Ponto de Partida (Pivot Point): Inicia-se com um dado conhecido simples (ex: nome de domínio, e-mail de um colaborador ou apelido).
  2. Correlação e Pivoting: Usa-se esse dado para encontrar novos pontos de apoio (ex: domínio ➔ IP ➔ certificados SSL ➔ subdomínios ➔ e-mails ➔ redes sociais).
  3. Análise Crítica: Separar "ruído" de inteligência real. Validar se a informação encontrada é verídica e pertence de fato ao alvo.

2. Ferramentas Essenciais de OSINT

Ferramenta Propósito Link de Acesso
OSINT Framework Árvore interativa estruturada reunindo centenas de fontes e serviços de inteligência. osintframework.com
Shodan Motor de busca global focado em portas abertas, banners e dispositivos IoT. shodan.io
Exploit-DB & GHDB Repositório de exploits e catálogo de Google Dorks para encontrar falhas públicas. exploit-db.com
Maltego Software líder em mineração de dados gráficos e análise de relacionamentos em grafos. maltego.com
FOCA Extração e análise forense de metadados em arquivos públicos (PDF, DOCX, XLSX). GitHub FOCA

3. Google Hacking (Google Dorks Cheat Sheet)

Técnica que utiliza operadores avançados de pesquisa no Google para indexar e revelar arquivos confidenciais e painéis expostos:

# Encontrar diretórios com listagem aberta de arquivos (Directory Listing):
site:alvo.com intitle:"index of /"

# Encontrar planilhas com potenciais credenciais ou dados sensíveis:
site:alvo.com filetype:xls intext:"password"

# Encontrar arquivos de banco de dados ou backups desprotegidos:
site:alvo.com ext:sql | ext:bkp | ext:env

# Localizar painéis administrativos expostos:
site:alvo.com inurl:admin OR inurl:login

4. Shodan (O "Google dos Dispositivos")

Filtros práticos para busca direcionada no Shodan:

# Localizar servidores Microsoft RDP (porta 3389) em uma faixa de IPs:
port:3389 net:192.168.1.0/24

# Encontrar painéis de bancos de dados MongoDB abertos sem autenticação:
"MongoDB Server Information" port:27017 -authentication

# Localizar servidores Apache de uma organização específica:
org:"NomeEmpresa" product:"Apache"

5. FOCA e a Mineração de Metadados

A extração de metadados em arquivos institucionais públicos revela:

  • Nomes reais e logins de usuários de rede que criaram ou salvaram os documentos.
  • Caminhos internos de pastas do servidor (ex: C:\Users\joao.silva\Projetos\...).
  • Softwares utilizados e suas respectivas versões desatualizadas.
  • Nomes de impressoras e compartilhamentos SMB corporativos.
